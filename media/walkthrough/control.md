## You stay in control

- **Approvals** — Codico asks before it changes a file or runs a command, and shows the diff or the command first.
- **Undo / Redo** — the ↶ ↷ buttons at the top revert or reapply Codico's last file change.
- **Edits mode** — queue every change for review and accept or reject each one.
- **Stop** — the Stop button (or Esc) ends the reply at once.
- **Edit, delete, regenerate** — hover one of your messages to change it and run the turn again.
