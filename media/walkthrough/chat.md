## Ask for something

Open the chat and describe what you want in plain words, for example:

- *Explain how this project is organised*
- *Fix the errors in the Problems panel*
- *Write tests for the open file*

Three modes sit above the message box:

- **Ask** — read-only: Codico searches and explains, and changes nothing.
- **Plan** — Codico writes a step-by-step plan first; you approve it before anything runs.
- **Agent** — Codico reads, edits and runs commands until the task is done.

Type `/` for commands and `@` to pick a specialised agent. Drop files or images onto the chat to attach them.
